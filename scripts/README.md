# 🔧 Utility Scripts

**Automation scripts for Cleanup Tracker**

---

## Available Scripts

### 🏗️ build.sh
**Purpose:** Build the application for production

**Usage:**
```bash
./scripts/build.sh
```

---

### 🚀 deploy.sh  
**Purpose:** Deploy application to production server

**Usage:**
```bash
./scripts/deploy.sh
```

**Prerequisites:**
- Production server access
- Environment variables configured
- MongoDB connection established

---

### 🛡️ add_error_handling.sh
**Purpose:** Add comprehensive error handling to codebase

**Usage:**
```bash
./scripts/add_error_handling.sh
```

---

### 🔌 create_endpoints.sh
**Purpose:** Generate new API endpoints from templates

**Usage:**
```bash
./scripts/create_endpoints.sh
```

---

## 💡 Tips

**Make all scripts executable:**
```bash
chmod +x scripts/*.sh
```

**Run from project root:**
```bash
./scripts/[script-name].sh
```

**Check script before running:**
```bash
cat scripts/[script-name].sh
```
